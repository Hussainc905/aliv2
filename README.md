# ELYAS FUN V3 — Android prototype

**Version:** 3.0.0 — source project, not a prebuilt APK.

هذه النسخة تحتوي على **كود أندرويد معدل** لمشهد كامل مدته 51 ثانية، مع رسوم الطفل المستخدمة في النسخة السابقة وشكل مرجعي جديد ضمن `reference/`.

## المشهد الجديد

1. يفتح الباب، ويظهر الطفل بتعبير متضايق قليلاً.
2. يمشي مع سلم خشبي **محمول وقابل للطي** ويضعه بمكان التنظيف الأول.
3. يفتح السلم ويصعد، ويمسح أول بقعة مع حركة اليد والقماش.
4. ينزل ويطوي السلم ويحمله إلى مكان تنظيف ثانٍ.
5. يفتح السلم ويصعد مرة ثانية ويزيل بقعة ثانية مستقلة.
6. ينزل ويلتفت نحو المستخدم ويلوح بيده **باي باي**.
7. يطوي السلم ويعود إلى الباب، ثم يغلق الباب.

**الصوت:** تأثير فتح الباب فقط. يمكن تعطيله من التطبيق. لا موسيقى ولا صوت خطوات.

## قيود الجودة، مهمة جدًا

- التطبيق يستخدم Canvas وBitmap Mesh لتحريك رسومات **2.5D**. الصورة المرجعية `reference/V3_STORYBOARD_REFERENCE.png` توضح **الشكل السينمائي المستهدف فقط**؛ ليست فيديو ولا كادرات فعلية مدرجة في المشهد المتحرك.
- هذه ليست جودة فيلم Stop Motion/3D حقيقي بعد. للوصول إلى مستوى الفيلم المُرسل، يلزم تطوير شخصية ثلاثية الأبعاد متسقة وrig وعمل rendering للحركة، ثم دمج الناتج كمشهد فيديو/Alpha/سلسلة frames احترافية.
- صورة الطفل موجودة على هيئة رسومات محلية ضمن assets. يفضّل رفع المشروع إلى مستودع GitHub **خاص (Private)**.
- مدة المشهد ~51 ثانية. قد يختلف تفعيل التشغيل عند فتح قفل الهاتف حسب إصدار أندرويد وسياسة الخلفية.

## بناء APK على GitHub

1. فك ضغط ZIP على الحاسوب، وادخل إلى مجلد المشروع الداخلي.
2. ارفع **محتويات** المشروع إلى جذر مستودع خاص (Private) في GitHub، مع استبدال ملفات V2 القديمة.
3. انتبه أن ملف الـWorkflow يجب أن يكون في المسار الصحيح: `.github/workflows/android-apk.yml`، وليس `workflows/android-apk.yml`.
4. افتح Actions ثم `ELYAS FUN V3 - Build Android APK` واضغط Run workflow.
5. بعد نجاح البناء حمّل Artifact باسم `ELYAS_FUN_V3_APK` واستخرج منه ملف `app-debug.apk`.

## حالة التحقق

فحصنا الملف المضغوط، المسارات، وتوافق أسماء الأصناف والكود بشكل ثابت. لم يتوفر Android SDK لتشغيل Gradle أو لاختبار التطبيق على هاتف هنا، وبالتالي **نجاح بناء APK غير مؤكد قبل تجربة GitHub Actions**.
